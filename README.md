# 📈 股票模拟器：百万之路

> 用¥10,000在750天内变成¥1,000,000！

一个基于React + TypeScript + Vite构建的股票模拟交易游戏。

## 🎮 游戏功能

- 📊 K线图表
- 📰 新闻系统
- 🏪 道具商城
- 🎰 彩票玩法
- 🏦 银行系统
- 💼 资产管理
- 📊 个人统计
- 🏆 成就系统
- ⚙️ 设置页面
- 💾 数据导入导出

## 🎯 游戏目标

| 项目 | 数值 |
|------|------|
| 初始资金 | ¥10,000 |
| 目标资金 | ¥1,000,000 |
| 时间限制 | 750天 |

## 🎮 玩法说明

### 交易阶段
1. 开盘阶段 → 交易时间
2. 午间休市 → 只能看盘
3. 收盘阶段 → 交易 + 商城开放

### 快捷键
- 空格 / 回车 → 下一步
- ESC → 关闭弹窗

## 📦 安装和运行

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 生产构建
npm run build
```

## 🛠️ 技术栈

- React 18
- TypeScript
- Vite
- ECharts
