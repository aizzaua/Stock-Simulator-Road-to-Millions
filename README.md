# 📈 股票模拟器：百万之路

> 用¥10,000在750天内变成¥1,000,000！

一个基于React + TypeScript + Vite构建的股票模拟交易游戏，采用GitHub深色主题风格，包含真实的K线图表、新闻系统、道具商城和彩票玩法！

## 🎮 游戏特色

### 📊 真实K线图
- 使用ECharts展示专业蜡烛图
- 包含MA5、MA20均线
- 成交量图表
- 支持缩放和拖放

### 📰 新闻系统
- 每日新闻影响股价
- 利好/利空新闻提示
- 相关股票标注

### 🏪 道具商城
- **收盘阶段**开放购买
- 道具即时生效

### 🎰 彩票玩法
- 三档彩票可选
- 最高100倍奖金
- 即时开奖动画

### 💼 资产管理
- 实时计算总资产
- 今日收益显示
- 目标进度条

## 🎮 玩法说明

### 一天流程
1. **开盘阶段** → 交易时间
2. **午间休市** → 只能看盘，不能交易
3. **收盘阶段** → 交易时间 + 商城开放
4. **进入下一天** → 按空格键或点击"下一步"

### 交易规则
- 每次交易收取0.1%手续费
- 点击股票列表查看详情
- K线图显示历史数据
- 在"我的持仓"管理你的投资组合

### 快捷键
| 按键 | 功能 |
|------|------|
| 空格 / 回车 | 推进到下一阶段 |
| ESC | 关闭弹窗 |

## 🎲 游戏机制

### 股价生成
- 每只股票有基础波动率和趋势
- 正态分布随机波动
- 新闻影响当日趋势
- 开盘、午间、收盘三个阶段价格变动

### 股票分类（18只）
- **科技股** (6只)：高波动，高增长
- **消费股** (6只)：稳健，低波动
- **娱乐股** (6只)：高波动，风险高
